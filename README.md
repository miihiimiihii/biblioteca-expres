# Biblioteca Exprés

Repositorio de prácticas Git y GitHub para la gestión
de una biblioteca ficticia.

## Funcionalidades

- Catálogo de libros
- Gestión de préstamos
- Gestión de lectores

## Objetivo

Practicar el control de versiones y la colaboración
mediante Git y GitHub.
Horario: lunes a sábado

Avisos: consultar novedades en recepcion
